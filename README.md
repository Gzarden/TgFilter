# TgFilter

Маленькое Android-приложение для Xiaomi. Следит за уведомлениями Telegram и удаляет
уведомления одного канала, когда сейчас не время, когда их нужно видеть (вечером, ночью, в выходные).

## Как собрать APK

**Вариант А. GitHub Actions (ничего ставить не нужно)**
1. Создай репозиторий на github.com и загрузи в него все файлы этой папки (включая скрытую `.github`).
2. Открой вкладку Actions, дождись зелёной галочки у сборки «Build APK».
3. Внутри сборки скачай артефакт `TgFilter-apk`, в нём `app-debug.apk`.

**Вариант Б. Android Studio**
1. File → Open → выбери папку TgFilter, дождись синхронизации Gradle.
2. Build → Build APK(s). Файл появится в `app/build/outputs/apk/debug/`.

## Установка и настройка

1. Скопируй `app-debug.apk` на телефон и установи (разреши установку из этого источника).
2. Открой TgFilter и нажми «Открыть доступ к уведомлениям», включи переключатель TgFilter.
   - Если переключатель серый или пишет «Ограниченная настройка»: Настройки → Приложения →
     TgFilter → ⋮ (меню вверху справа) → «Разрешить ограниченные настройки», потом снова включи доступ.
3. Дождись любого уведомления от нужного канала. Его название появится в списке
   «Недавние уведомления Telegram». Нажми на него, и оно подставится в поле.
4. Задай интервал, когда уведомления можно показывать (по умолчанию 10:00–18:00),
   и оставь включённым «Не показывать в выходные».

## Чтобы Xiaomi не выгружал приложение

- Настройки → Приложения → Разрешения → Автозапуск → включить для TgFilter.
- Настройки → Приложения → TgFilter → Экономия заряда → «Нет ограничений».
- В списке недавних приложений зафиксируй TgFilter (долгое нажатие на карточку → замок).

## Как это работает и ограничения

- Приложение не может заблокировать уведомление до показа. Оно удаляет его сразу после появления,
  обычно это доли секунды. Чтобы не было даже звука, в самом Telegram поставь для этого канала
  «Без звука» или отключи звук уведомлений.
- Совпадение ищется по названию канала в заголовке уведомления (регистр не важен).
- Если в шторке остаётся пустая сводка «N сообщений», это групповое уведомление Telegram.
  Тогда скажи, и я добавлю для него отдельное правило.
