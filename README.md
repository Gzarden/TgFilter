# TgFilter 2.0

Android-приложение: скрывает уведомления выбранных каналов Telegram вне заданного времени.

## Что нового во второй версии

- **Журнал**: каждое уведомление Telegram записывается с заголовком, текстом, служебными полями и решением («скрыто», «показано», «другой чат», причина). Журнал можно скопировать и отправить.
- **Несколько каналов**: у каждого своё время показа и свои дни недели.
- **Сводка пропущенного**: когда начинается время показа, приходит одно уведомление «Канал: пропущено N постов».
- **Статус работы** вверху главного экрана: что не так и что нажать, чтобы исправить.
- Обновление данных потягиванием вниз, автообновление при открытом приложении, тёмная тема.

## Как обновить

1. Удалите старую версию с телефона (Настройки → Приложения → TgFilter → Удалить).
   Нужно один раз: версия 2 подписана постоянным ключом, а версия 1 была подписана случайным.
   Дальше все обновления будут ставиться поверх без удаления.
2. На GitHub: Add file → Upload files, перетащите папку `app` из архива, затем Commit changes.
3. Подождите зелёную галочку во вкладке Actions и скачайте APK из Artifacts.
4. Установите, откройте, выдайте доступ к уведомлениям (кнопка в статусе).

## Если что-то не работает

Откройте вкладку «Журнал», нажмите «Скопировать» и отправьте текст разработчику.
Если нужно понять, доходят ли уведомления до телефона вообще, включите в журнале
«Записывать уведомления всех приложений».

## Ограничения

- Уведомление удаляется сразу после появления (доли секунды). Чтобы не было звука,
  поставьте каналу в Telegram «Без звука».
- Сводка пропущенного приходит в начале времени показа с возможной задержкой в несколько минут
  (так работает экономия энергии Android).
